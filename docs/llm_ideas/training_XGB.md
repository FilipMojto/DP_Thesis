3. Fixing the "Signal" (The 0.66 AUC)A $0.66$ AUC suggests that the model is struggling to find features that truly separate the classes. Since you are using CodeBERT, the issue is likely Feature Dilution.If your diffs are long, Mean Pooling (averaging all tokens) is likely killing your performance.The Problem: If a bug is 2 lines of code in a 50-line diff, the "bug signal" is only 4% of the vector. The other 96% is "clean code signal." When you average them, the 96% drowns out the 4%.The Fix: Try using the [CLS] token or Max Pooling. Max pooling is particularly good for bug detection because it captures the "most anomalous" signal in the sequence rather than the "average" signal.
